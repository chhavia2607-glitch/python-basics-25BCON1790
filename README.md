# python-basics-25BCON1790

A repository containing basic Python scripts demonstrating foundational programming concepts including data structures (lists and dictionaries), mathematical computations (factorial and multiplication tables), sequence generation (Fibonacci), and pattern printing.

## Programs Included

* **`dictionary.py`**: Demonstrates Python dictionary operations such as key-value pair creation, access, modification, and iteration.
* **`factorial.py`**: Calculates the factorial of a given number using iterative or recursive logic.
* **`fibonacci.py`**: Generates and displays the Fibonacci sequence up to a specified number of terms or limit.
* **`list.py`**: Demonstrates various operations on Python lists, such as indexing, slicing, appending, and list manipulation.
* **`multiplication.py`**: Generates and prints multiplication tables for a given input number.
* **`pattern.py`**: Prints various geometric/star patterns using nested loops.

## Requirements / Dependencies

* **Python 3.x**: No external third-party libraries are required. All programs run using Python's built-in standard library.
