# python-basics-25BCON1790

A repository containing basic Python scripts demonstrating foundational programming concepts, operations with dictionaries, factorial calculation, and Fibonacci sequence generation.

## Programs Included

* **`dictionary.py`**: Demonstrates Python dictionary operations (creation, access, modification, key-value iteration).
* **`factorial.py`**: Calculates the factorial of a given number.
* **`fibonacci.py`**: Generates and displays the Fibonacci sequence.

## Requirements / Dependencies

* **Python 3.x**: No external third-party libraries are required. All programs run on standard Python.
